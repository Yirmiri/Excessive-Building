## Overhaul Update || v4.0.0 MC-1.21.1

### Important
- [WARNING] Excessive Building has been entirely overhauled both code, art, and also concept wise so [DO NOT UPDATE EXISTING WORLDS OTHERWISE THEY WILL BREAK !!!]
- I will be writing this changelog as if everything is the new for the sake of time, and any (Neo)Forge players who missed out on some content

### Building Tools
- Gauntlet: Crafted from amethyst shards/blocks, copper ingots, and an ancient fruit
    - Decreases the delay between placing blocks
    - Allows the player to interact with blocks from up to 3 blocks further away
    - Has increased knockback and attack damage to allow pushing unwanted visitors away
- Mallet: Crafted from amethyst shards and copper ingots
    - Has increased destroy speed for any blocks that do not have an assigned tool including some extra blocks
    - Can be used on some blocks to change them into new blocks

### Lavender, Sage, and Coralsoil
- Lavender and sage now generate throughout the world and can be used as crafting ingredients
- New clay blocks can be made from lavender, sage, and dead coral
- The new clay blocks can be turned into small bricks and hardened clay which hardened clay can create terracotta and clay bricks
- Added lavender and sage bales which work similarly to hay bales

### Dyed Blocks
- Almentra: A stone that can be dyed any color, generates high up in Mountain biomes
    - Almentra can be interacted with a mallet to create an almentra statue, each dye color has a different statue design
- Corrugated Iron: Crafted from iron and dyes and rotates like a pillar block
    - Has stairs and slabs
- Frosted Glass: Crafted from smelting glass and can be dyed
    - Can change beacon light colors
    - Allows light to pass through despite being fully opaque
    - Can craft frosted lanterns which create particles based on the dye color, the particles will fall or rise based on if its hanging

### Misc Blocks
- Wintergreen Wood Set: A mint wood that can be found in Taigas and Snowy Plains biomes
- Ancient Wood Set: A white wood which have a chance to drop when Sniffers sniff up items
- Aridite: An orange stone that can be found as clusters underground in Desert biomes
- Chloroslate: A green stone that can be found as clusters underground in Jungle biomes
- Hectalite: A blue stone that can be found as clusters around water underground
- Sitrite: A beige stone that can be found as clusters underground in Swamp biomes
- Malachite: A mint stone that can be found as clusters in Mountain biomes
- Conglomerate: A multicolored stone that can be crafted from cobblestone and gravel
- Brimstone: A red stone that can be found as clusters in the Nether

### Vanilla Additions
- Added cobblestone bricks, can be cracked
- Added granite, diorite, and andesite bricks which all have different designs
- Added smooth bricks, crafted from smelting bricks
- Added gemstone blocks for Amethyst, Lapis, Diamond, and Emerald
    - Framed Glass: Crafted from iron and gems, requires a pickaxe to efficiently mine and has high blast resistance
    - Gemstone Lanterns: Crafted from iron and gems
    - Gemstone Bricks: Crafted from x1 gem and x8 copper ingots and outputs x24
- Added copper bricks
