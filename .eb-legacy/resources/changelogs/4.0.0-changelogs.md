## Excessive Building Release v4.0.0 MC-1.20.1

### Notes
- Updated the License, check the LICENSE file for more information if this concerns you
- The Ancient woodset has had it's named changed from "Ancient" to "Bloodroot", the id will remain Ancient 
however in 1.21 and up it will be changed to "Bloodroot".
For the sake of understandability any reference to Bloodroot will be referred to as Ancient in this changelog
- The above change applies to "Ancient Pottery Sherd" and "Ancient Fruit", those now being "Consume Pottery Sherd" and "Life Fruit"

### Game Breaking Changes (Be weary before updating!)
- Removed Gloom trees and their woodset
- Removed Jars and Wooden Mugs (did not feel as though they fit), FYI: Almentra Statues WILL STAY but are now forced on without a config anymore
- Updated the id of Hasty and Fatigued potions to Endurance and Fatiguing potions (this will break existing potions)
- Removed Amethyst Lamp (moved to a new project)
- Removed Wooden Boards (removal only affects 1.21+ worlds)
- Removed all Roses (moved to a new project)
- Removed Cracked Mud Bricks
- Removed terrain.png and original variant paintings

### Additions
- Added a new configuration being "enableMiscTooltips" which adds tooltips to some items like pottery sherd authors (enabled by default)

### Changes
- Updated the minimum FabricAPI version from `0.16.0` to `0.16.13`
- The following configs had their defaults changed to false: "enableShelfVariants", "enableCraftingTableVariants", and "enableLadderVariants"
- The player now more accurately reflects the block's direction when placing Vertical Stairs
- Ancient Leaves can no longer remove their glow from Paper
- Excessive Building's pottery sherds created by Azurune community members now display a tooltip of the author

### Misc
- Updated the texture of most Ancient blocks and items from white to red (this is due to the Pale Garden featuring a white woodset)
- When wooden variant blocks are disabled their oak variants will no longer appear in the Excessive Building creative tab
- Knitted Carpets are now ordered after knitted wools in the creative inventory
- Chests are no longer in the Excessive Building creative inventory
- Moved the "enableCustomTooltips" config value to a misc category
- Polished Almentra and Almentra Statues now use the Polished Deepslate sound group
- Updated `tooltip.block.soul_magma` from "Creates a Lifting Bubble Column" to "Reverses Bubble Column Direction"
- Updated `tooltip.block.player_nearby` from "When Nearby" to "While Nearby"
- Updated the name for "Vanilla Retextures" to "Excessive Building Re-textures"
- Updated some author names on paintings;
"Drisfsh" -> "drisfsh"
"Nebula" -> "NebulaIsMine"
"YesMan2" -> "Cast Iron Skillet"
- Contributor capes have been removed as they are now present in RunicLib

### Fixes
- Fixed missing particles on Ancient Signs and Ancient Wall Signs
- Fixed the "Goodie Malk" painting
